# 📱 CARPZONE sur iPhone - Guide d'installation

## ✅ Prérequis

- iPhone avec Safari (iOS 12.2 ou plus)
- Internet (WiFi ou 4G)
- L'app est déployée sur Netlify (HTTPS)

---

## 🚀 Installation en 30 secondes

### Étape 1: Ouvrir Safari

1. Sur votre iPhone, ouvrez **Safari**

### Étape 2: Aller sur CARPZONE

Tapez dans la barre d'adresse:
```
https://VOTRE-SITE.netlify.app
```

Exemple:
```
https://carpzone-fishing.netlify.app
```

### Étape 3: Ajouter à l'écran d'accueil

1. Tapez le bouton **Partager** (icône carré avec flèche)
2. Scroll vers la droite
3. Tapez **"Ajouter à l'écran d'accueil"**

### Étape 4: Confirmer

1. Vérifiez que l'icône s'affiche
2. Le nom par défaut est "CARPZONE"
3. Tapez **"Ajouter"** (coin supérieur droit)

### ✅ C'est fait!

L'app apparaît maintenant sur votre écran d'accueil! Tapez l'icône pour la lancer.

---

## 🎯 Comment ça fonctionne

**Mode Normal** (via Safari):
- Barre d'adresse visible
- Boutons Safari visibles
- Interface Safari standard

**Mode Installé** (via écran d'accueil):
- Plein écran sans interface Safari
- Fonctionne comme une app native
- Peut fonctionner hors ligne

---

## 💾 Les données

- Vos sessions, prises, spots, appâts, notes sont sauvegardés **localement**
- Aucune connexion serveur requise
- Les données persistent même si vous fermez l'app
- Elles sont **privées** sur votre téléphone

## 🔄 Mettre à jour

Si vous avez des mises à jour:

1. Ouvrez Safari
2. Allez sur `https://VOTRE-SITE.netlify.app`
3. L'app se met à jour automatiquement

Ou (après installation):
1. Ouvrez l'app installée
2. Tirez la page vers le bas pour rafraîchir
3. Les données que vous aviez sont conservées

## ⚙️ Paramètres iOS

### Désactiver le zoom

CARPZONE est optimisée pour la lecture sans zoom. Si le contenu parait petit:

1. **Réglages** → **Safari**
2. **Taille de police** → Augmentez
3. (Ou pincez pour zoomer temporairement)

### Activer la géolocalisation (pour les spots GPS)

1. **Réglages** → **Confidentialité** → **Localisation**
2. Trouvez **Safari** ou **CARPZONE**
3. Changez à **"Pendant l'utilisation de l'app"**

## 🆘 Problèmes courants

### "L'app ne s'installe pas"

✅ **Solution:**
- Utilisez iOS 12.2 ou plus
- Assurez-vous que l'URL commence par `https://`
- Rafraîchissez la page (tirez vers le bas)

### "Les données ont disparu"

✅ **Explication:**
- Les données sont stockées localement (localStorage)
- Elles sont conservées même après fermeture
- Si vous videz l'historique/le cache de Safari, elles peuvent être perdues

✅ **Prévention:**
- Faites régulièrement des sauvegardes (export JSON si disponible)

### "L'app se ferme"

✅ **Solutions:**
- Actualisez la page
- Fermez et rouvrez l'app
- Vérifiez votre connexion Internet
- Vérifiez votre espace de stockage iPhone

### "Les boutons ne répondent pas"

✅ **Solutions:**
- Vérifiez que la page a fini de charger
- Ouvrez la Console (F12 sur Mac en mode développeur)
- Cherchez les erreurs rouges
- Actualisez la page
